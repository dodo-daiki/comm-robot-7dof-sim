# 7-DOFコミュニケーションロボット 骨格シミュレーター

7自由度(7-DOF)のコミュニケーションロボットの骨格・外装設計を、ハードウェアを確定させる前にブラウザ上でおおまかに検討するためのシミュレーターです。関節配置・可動域(ROM)・リンク寸法・モーター選定を、実機を作る前に試行錯誤できます。

### ▶ [ここでビューアを開く(ダウンロード不要)](https://dodo-daiki.github.io/comm-robot-7dof-sim/viewer/robot_viewer.html)

GitHub Pagesでホスティングしているため、クリックするだけでブラウザ上でそのまま動作します。リポジトリをクローン/ダウンロードする必要はありません。

## このリポジトリの構成

本リポジトリは大きく2部構成です。

### 1. `viewer/robot_viewer.html` — メインツール

単一の自己完結HTMLファイルです。Three.jsも完全にインライン化されており、外部依存・ネットワーク通信は一切ありません。ブラウザで直接開くだけで動作します(ダブルクリック、`file://`表示、どんな静的ホスティングでも可)。**インストールもサーバーも不要**で、このプロジェクトの主な使い方はこのファイルを開くことです。

### 2. `robot/`, `data/`, `tests/` — Pythonリファレンス実装

運動学(`kinematics.py`)、PETG質量推定(`mass_estimator.py`)、GIM4310モータースペック(`motor_specs.py`)、静的重力トルク計算(`dynamics.py`)のPython実装です。JSビューア側の数式はこちらから移植され、開発の各段階でこの実装に対してクロス検証されています。あくまで開発時の「正解データ(ground truth)」であり、ビューアを使うだけであれば実行する必要はありません。

## 主な機能

- 各関節のポーズ(角度)をスライダーで操作
- パネルは「骨格パーツ」と「関節」の2系統に分離:
  - **骨格パーツ**: 胴体・鎖骨・首・頭部・上腕・前腕・手など、体の部位ごとにリンク長・太さ・取付角度・重量(自動推定 or 直接指定)を編集
  - **関節**: 回転軸・可動域(ROM)・モーター機種など、各軸(モーター)固有の設定を編集
- 3Dモデルを直接クリックして、対応するパーツ/関節の設定にジャンプ可能
- GIM4310モーターを実寸スケールのシリンダーで表示
- プリセット動作5種を再生: うなずき・首振り・手を振る・会釈・アイドル(常時ループ)
- 自作動作(カスタム動作)エディター: 複数関節を同時に動かすキーフレームアニメーションをその場で記録し、JSON形式でエクスポート/インポート可能
- 現在のポーズでの各関節モーターの負荷をライブ推定(定格トルク・ストールトルクに対する割合を色分け表示、ペイロード質量・パーツ重量にも対応)

## 既知の運動学的な制約

開発中に判明した、現行7-DOFレイアウトの制約です。実機の関節レイアウトを詰める際の参考にしてください。

- **腰ピッチ(waist pitch)がない** — 上半身を前に倒す動作ができず、本当の意味での「お辞儀」は再現できません
- **肩のロール/ヨーがない** — 腕はピッチ(前後)方向にしか動かせず、横に開く・横から振るような動作はできません

## データソース・注意事項

GIM4310-10 / GIM4310-36 のモータースペック(トルク・重量・寸法)は、開発時に以下の公開の販売代理店/データシートページから収集したものです。

- GIM4310-10: <https://aifitlab.com/products/steadywin-gim4310-10-planetary-reducer-servo-motor>
- GIM4310-36: <https://lucidar.me/en/actuators/mit-motor-gim4310-36/>

`robot/motor_specs.py` 内のコメントにもある通り、これらは正式なメーカーデータシートからの転記ではないため、**実機発注前に必ず公式データシートで確認**してください。

また、リンク長・PETG質量推定・モーター選定は、いずれも仮のデフォルト値です。最終的な設計値ではなく、ビューアのパネル上で実際の設計に合わせて調整することを前提としています。

## Pythonテストの実行

リファレンス実装(運動学・質量推定・トルク計算)を検証したい場合は、リポジトリルートで以下を実行します。

```bash
python -m venv .venv
# Windows
.venv\Scripts\activate
# macOS / Linux
source .venv/bin/activate

pip install -r requirements.txt
pytest
```

venv(仮想環境)の使用を推奨します(標準的なPython開発手順です)。
